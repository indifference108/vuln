# 中国农业大学信电学院本科生综合测评平台_默认弱口令漏洞_报告（中文）

## 1. 标题

中国农业大学 信电学院本科生综合测评平台（120.46.187.29:8900）存在默认弱口令漏洞（初始密码=学号后六位，可登录任意学生账号并冒用身份填报/评分）

## 2. 漏洞概述

中国农业大学信息与电气工程学院「本科生综合测评平台」（http://120.46.187.29:8900，公网可达的裸 IP 服务）存在弱口令漏洞。攻击者无需任何授权，仅利用学院自行公开的两类信息——初始密码规则与本科生学号公示名单——即可登录任意在册学生账号。

初始密码规则为「学号后六位」，由中国农业大学信电学院官网《关于开展2025—2026学年本科生综合素质测评工作的通知》（落款 2026-08-21）原文公开，且系统未强制首次登录修改密码；学号由信电学院官网 2026 年 9 月发布的 2027 届推免拟推荐名单公示 PDF 明文公布，两份 PDF 合计含 151 个完整学号（2023 级在读本科生）。

## 3. 受影响产品与版本

- 产品：中国农业大学信电学院 本科生综合测评平台（学院自研系统，前端 React / 后端 FastAPI，JWT 认证）
- 入口：http://120.46.187.29:8900/（登录 API：POST /api/v1/auth/login）
- 涉事 IP：120.46.187.29:8900（华为云北京，公网直连，无验证码、无登录频率限制）
- 影响账号范围：信电学院 2023、2024、2025 级全体在册本科生（每级数百人）
- 验证环境：Windows / Chrome / Python requests，公网环境，2026-10-13

## 4. 根因分析

漏洞根因是**初始密码由学号直接派生（可公开枚举）、系统不强制首登改密、无任何登录防护**：

1. 信电学院官网通知原文：「登录账号为学生本人学号，初始密码为学号后六位（请大家第一次登陆后及时修改密码以确保数据安全）」——密码仅为公开学号的子串，属于 CWE-521（Weak Password Requirements）。
2. 学号由学院官网推免公示 PDF 明文公开（151 个 13 位学号），构成完整凭据来源，攻击者零成本获得账号+密码。
3. 系统侧无首次登录强制改密、无密码复杂度校验、无验证码、无异常登录告警、无登录频率限制，凭据长期有效。实测 144 个公示学号中 8 个直接使用初始密码登录成功，默认密码未修改比例约 1/17（且填报窗口刚结束，多数学生尚未登录改密）。
4. 涉事服务部署于公网裸 IP（120.46.187.29:8900），无任何网络层访问控制，互联网任意主机可直接访问认证接口。

数据流：攻击者读取学院通知（获得密码规则）→ 读取推免公示 PDF（获得学号）→ POST /api/v1/auth/login（学号+学号后六位）→ 认证通过获得 JWT → 获得目标学生账号完整权限。

## 5. CVSS 评分

- CVSS v3.1：**9.1（严重 Critical）**，向量 `CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:N`
- CWE-521（Weak Password Requirements）
- 评分依据：攻击来自网络、无需权限与受害者交互；凭据全部来自校方公开信息；平台内置综测加分材料上传、班级民主测评打分等写功能，可冒用任意学生身份填报与评分，机密性与完整性影响均为高（验证全程仅登录成功即止，未浏览、未执行任何业务操作）；可用性无直接影响。

## 6. 漏洞证明（POC）

见同目录 `poc/verify_cau_zcpj_weakpass.py`（只读验证脚本：检查目标可达性、登录页特征、以官方规则推导凭据并尝试登录，登录成功即停止，不调用任何业务接口）。核心复现步骤：

1. 访问 https://ciee.cau.edu.cn/art/2026/8/25/art_50390_1130314.html 获取密码规则（学号+学号后六位）。
2. 访问信电学院 2026-09 推免拟推荐名单公示页下载 PDF，取任一学号（如 2023303090501）。
3. 向 http://120.46.187.29:8900/api/v1/auth/login POST `{"username":"2023303090501","password":"090501"}`。
4. 实测结果（2026-10-13）：返回 200 + JWT access_token，登录成功。同批另验 7 个账号同样成功（共 8 个，清单见 evidence/02-登录成功账号清单.txt）。

## 7. 复现过程

1. **步骤一：确认系统公网可达**。访问 http://120.46.187.29:8900/，页面标题「中国农业大学信电学院本科生综合测评平台」。（录屏 1）
2. **步骤二：读取官方公开的密码规则**。访问学院通知原文页，可见「登录账号为学生本人学号，初始密码为学号后六位」。（evidence/01-学院通知-初始密码原文.txt）
3. **步骤三：获取公开学号名单**。下载 2027 届推免拟推荐名单 PDF（含追加公示），合计 151 个完整 13 位学号。（evidence/04/04b PDF）
4. **步骤四：登录验证**。以学号 2023303090501、密码 090501 调用登录接口，返回 200 与 access_token，登录成功。（录屏 2：登录全过程）
5. 验证即止：未访问 /auth/me 之外的任何业务接口，未读取任何学生数据。

## 8. 影响分析

- **机密性（高）**：可登录信电学院全体在册本科生账号，平台存储学生综测材料、个人信息、班级测评数据。
- **完整性（高）**：平台核心功能即「加分材料上传」与「班级民主测评打分」，攻击者可冒用任意学生身份提交材料、参与评分，直接影响评奖评优结果；亦可篡改他人已提交内容（本次验证全程未执行任何写操作）。
- **可用性（无）**：未发现对系统可用性的直接影响。
- **影响范围**：信电学院 2023、2024、2025 级全体本科生；综测结果直接挂钩奖学金评定，业务敏感性高。

## 9. 修复建议

**临时缓解（立即执行）**：
1. 立即将平台从公网裸 IP 收敛至校园网/VPN 后方可访问；
2. 对全体在册学生账号批量重置为随机一次性口令并短信/邮件通知本人；
3. 登录环节增加验证码与登录频率限制；
4. 增加异常登录监控（多账号同源登录、非校园网网段登录告警）。

**根治修复**：
1. 上线首次登录强制改密与密码复杂度策略（禁止与学号相关的弱口令）；
2. 初始口令一律改为一次性随机口令，禁止由学号派生；
3. 对公示类 PDF 的学号列做脱敏处理（保留前 4 位 + 后 2 位）；
4. 建立对外公示信息发布前的敏感信息审查机制。
