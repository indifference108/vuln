# 四川大学_本科教学助教管理系统_默认弱口令漏洞_报告（中文）

## 1. 标题

四川大学 本科教学助教管理系统（jxyw.scu.edu.cn:8081/yjszj/）存在默认弱口令漏洞（全校研究生统一固定初始口令，可登录任意学生账号）

## 2. 漏洞概述

四川大学「本科教学助教管理系统」（http://jxyw.scu.edu.cn:8081/yjszj/，公网可达）存在弱口令漏洞。攻击者无需任何授权，仅利用四川大学自行公开的两类信息——全校统一初始口令与研究生学号公示名单——即可登录任意在校研究生的账号。

初始口令为全校统一固定值：2025 级为 `Cd2023jxyth@`，2024 级及以前为 `cd2017jxyth`，由四川大学教务处官网通知原文公开；学号由四川大学研究生院官网"学业奖学金获奖名单公示"附件（xlsx）明文公布，单届硕士名单即含 4678 人（2025 级），2023 级硕士名单另含 4189 人。

## 3. 受影响产品与版本

- 产品：四川大学 本科教学助教管理系统（自研/校内系统）
- 入口：http://jxyw.scu.edu.cn:8081/yjszj/
- 涉事 IP：202.115.32.49（jxyw.scu.edu.cn 解析结果）
- 影响账号范围：全体在校研究生（硕士、博士），按多届公示名单累计数万人
- 验证环境：Windows / Chrome，公网环境，2026-10-02

## 4. 根因分析

漏洞根因是**初始口令采用全校统一固定值且长期不变更、系统不强制首登改密**：

1. 四川大学教务处 2025-11-17 发布《关于第三十期本科教学助教培训报名的通知》，原文："报名者登录'本科教学助教管理'系统(http://jxyw.scu.edu.cn:8081/yjszj/，用户名：学号，初始密码：2025级新进研究生的初始密码：Cd2023jxyth@和2024级及以前研究生的初始密码：cd2017jxyth）"。同一口令面向全校学生公开，属于 CWE-521（Weak Password Requirements）。
2. 学号属于可枚举标识符，且四川大学研究生院官网以 xlsx 附件明文公示各届研究生学号与姓名，构成完整凭据来源。
3. 系统侧无首次登录强制修改密码、无密码复杂度校验、无异常登录告警，凭据长期有效；登录验证码仅提高自动化成本，不构成凭据强度。

数据流：攻击者读取教务处通知（获得全校统一口令）→ 读取研究生院公示附件（获得目标学号）→ 在登录页输入学号+口令+验证码 → 登录接口 `/yjszj/login` 认证通过 → 获得目标学生账号完整权限。

## 8. 影响分析

- **机密性（高）**：可登录任意在校研究生账号，查看其个人信息、助教报名与岗位相关信息，涉及数万名学生。
- **完整性（高）**：系统内置助教报名等写功能，攻击者可冒用学生身份发起报名、修改报名信息（本次验证全程只读，未执行任何写操作）。
- **可用性（无）**：未发现对系统可用性的直接影响。
- **影响范围**：全体在校研究生；系统已面向多届学生长期使用，历史账号凭据长期有效。

## 9. 修复建议

**临时缓解（立即执行）**：
1. 立即停用全校统一固定初始口令，对存量账号批量重置为随机一次性口令并通知本人；
2. 在登录环节增加短信/邮箱二次验证；
3. 增加异常登录监控（异地登录、多账号同源登录告警）与登录频率限制；
4. 对历史通知中的口令做失效处理。

**根治修复**：
1. 上线首次登录强制改密与密码复杂度策略；
2. 初始口令一律改为一次性随机口令，禁止全校共用固定口令；
3. 对公示类附件的学号列做脱敏处理（保留前 4 位 + 后 2 位）；
4. 建立对外公示信息发布前的敏感信息审查机制。
