## 1. 产品介绍

福建农林大学研究生综合服务平台（URL 路径含 `/gsapp/`，为强智科技 gsapp 架构的研究生教育管理信息系统，厂商归属待确认）是该校研究生院用于研究生学籍、培养、学位、证明打印等业务的管理系统。该系统公网可访问，提供三种登录入口：统一身份认证入口、系统账号登录入口、校外导师登录入口。本次漏洞位于其「系统账号登录入口」。

---

## 2. 漏洞标题

福建农林大学研究生综合服务平台存在毕业研究生账号弱口令漏洞（任意毕业生账号可登录）

---

## 3. 漏洞描述

福建农林大学研究生综合服务平台的「系统账号登录入口」（面向已毕业研究生）账号为学号，初始密码规则为「学号@学号后四位」。该校研究生院官网的「授予学位公示」附件（xlsx）以明文批量公布毕业生的姓名与学号（实测 2024 年 12 月一批即 36 人完整学号）。攻击者无需任何授权，仅用公开信息即可推导出任意已毕业研究生的登录凭据，批量登录其账号，读取该生的学籍、培养环节、成绩、学位等全部数据，并可冒用其名义发起证明打印申请。2026-10-01 晚实测使用该规则构造的凭据一次登录成功。漏洞导致毕业生群体个人信息机密性受到严重威胁。

---

## 4. 漏洞分析

**根因类型**：CWE-521 弱口令需求（Weak Password Requirements），初始口令由公开学号按固定规则直接推导；伴随 CWE-200 敏感信息泄露（公示附件明文学号）作为凭据来源。

未获源码，以下为黑盒判定。

**Source-to-sink 调用链**（凭据均为公开信息，非越权获取）：

```
Source 1（官方手册，URL: https://yjsy.fafu.edu.cn/63/04/c3665a418564/page.htm）
  原文：「已毕业学生使用"系统账号登录入口"，账号是学号，初始密码为"学号@学号后四位"」
Source 2（学位授予公示附件 xlsx，明文列：序号/专业/姓名/学号/导师/学位类别）
  示例：https://yjsy.fafu.edu.cn/_upload/article/files/4d/14/71370c0d444881c135cc0bc0046a/76fb23db-3f00-4b2e-8762-8196e36266e8.xlsx
凭据构造：userId = 学号；password = 学号 + "@" + 学号后四位
Sink：POST /gsapp/sys/yjsrzfwapp/dbLogin/index.do（字段 userId / password / vcode）
```

**有效性判定**（黑盒）：
- 可达：✅ 登录口公网可达，无 VPN/白名单限制
- 可控：✅ 学号取自官方公示附件，密码由规则唯一推导，零猜测
- 可传播：✅ 同一规则覆盖全部已毕业研究生（仅 2024 年三批博士已 179 人，硕士批次规模更大）
- 可利用：✅ 单次登录请求即成功（2026-10-01 实测）
- 防护可绕过：✅ 该入口对毕业生账号无首次强制改密、无复杂度校验、无登录异常告警
- 可复现：✅ 录屏 + 逐步截图，第三方可 1:1 复现
- 影响成立：✅ 登录后可见毕业生学籍/培养/成绩/证明打印等个人数据
- 影响范围：✅ 历届全部毕业研究生；若该校为厂商标准部署，其他使用同款 gsapp 平台的高校可能存在同配置问题（待厂商排查确认）

**成因分析**：平台给已毕业研究生分配的初始密码不是随机值，而是用学号加一个固定后缀拼出来的。学号又正好在学校自己的公示附件里明文躺着。两者一叠加，初始密码就成了公开可推导的信息，等于没有密码。

## 8. 漏洞复现过程

### 8.1 复现环境

- 产品/版本：福建农林大学研究生综合服务平台（线上版本）
- 系统/运行时：目标为公网 Web 系统；测试端 Windows 11 + Chrome
- 网络位置：公网
- 测试账号：无（凭据全部来自校方公开信息）

### 8.2 复现步骤

**步骤 1 — 获取初始密码规则（官方手册自证）**
打开研究生院官网操作手册页，可见「已毕业学生使用系统账号登录入口，账号是学号，初始密码为学号@学号后四位」。
> ![步骤1](evidence/01-manual.png)

**步骤 2 — 获取学号（官方公示附件）**
打开「授予学位公示」页面，下载附件 xlsx，内含毕业生明文姓名与学号（示例：路一平 2190101005）。
> ![步骤2](evidence/02-xlsx.png)

**步骤 3 — 构造凭据并登录**
按规则构造 userId=`2190101005`、password=`2190101005@1005`，在系统账号登录入口输入验证码后登录成功，进入研究生综合服务平台门户。
> ![步骤3](evidence/03-login-success.png)

**步骤 4 — 影响验证（只读）**
进入学籍/个人信息与证明打印列表页面，可查看该毕业生个人信息与业务数据。全程只读，未执行任何写操作。

## 9. 漏洞复现 POC

### 9.1 格式选择
- 选用格式：自定义脚本（Python）
- 选择理由：登录需人工输入图形验证码，无法全自动；脚本负责「凭据推导 + 登录可达性验证」，实际登录一步在浏览器中由人工完成验证码，脚本给出 1:1 操作指引。

### 9.2 运行说明
- 运行环境：Python 3.8+（仅依赖标准库 + openpyxl 解析公示附件）
- 代理到 Burp：`USE_BURP=1 BURP_PROXY=http://127.0.0.1:8080`（默认开）
- 安全声明：本 POC 仅用于授权测试与漏洞验证，禁止用于未授权系统。单账号单次验证，不含任何批量逻辑。

### 9.3 POC 代码

见 `poc/verify_fafu_alumni_login.py`。

### 9.4 预期输出 / 成功判定
```
[+] 登录页可达（HTTP 200，含 系统账号登录入口）
[+] 凭据推导：2190101005 / 2190101005@1005
[*] 请在浏览器打开登录页，选择「系统账号登录入口」，填入上述凭据并输入验证码登录
成功判定：登录后跳转至 https://yjsapp.fafu.edu.cn/gsapp/sys/yjsemaphome/portal/index.do（研究生综合服务平台门户）
```

## 10. 修复建议

### 10.1 临时缓解措施
- 毕业生系统账号登录入口增加短信/邮箱二次验证
- 立即对「授予学位公示」等附件中的学号列脱敏（保留前 4 位 + 后 2 位），并回溯清理历史附件
- 监控该入口异常登录

### 10.2 根治修复方案
- 毕业生账号默认停用；确需启用时由本人持有效证件走人工审核 + 一次性随机口令重置
- 初始密码规则改为不可推导的随机值，首次登录强制修改
- 公示名单类附件统一走脱敏发布流程，从制度上切断「学号 = 半公开信息」的现状

### 10.3 修复验证
重放本报告 POC：使用公示学号推导的凭据应无法再登录；公示附件中学号应已脱敏。
