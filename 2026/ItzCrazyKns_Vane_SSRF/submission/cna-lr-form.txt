## 字段 5：Vulnerability description

Server-side request forgery in the scrape_url tool of ItzCrazyKns Vane 1.12.2 and earlier. The unauthenticated POST /api/search endpoint passes user queries to an LLM agent whose scrape_url tool hands LLM-supplied URLs verbatim to Scraper.scrape(), which executes page.goto(url) via a server-side Playwright browser (launched with --no-sandbox). No scheme, hostname, or IP validation is performed at any point: internal network services, cloud metadata endpoints (e.g. http://169.254.169.254/), and local files via file:// URLs are all reachable, and fetched content is echoed back to the attacker in the API response. An unauthenticated remote attacker triggers this by inducing the LLM to call scrape_url with a chosen URL, either directly via the query text or indirectly via prompt injection in web content the agent reads.

## 字段 8：Additional information（可选，建议填）

- The vulnerability was publicly disclosed via GitHub issue #1140 on 2026-05-25 and remains unfixed; no CVE ID has been assigned to it. CVE-2026-9372 covers a different SSRF in the same product (model provider baseURL handling, issue #1124) and is not a duplicate.
