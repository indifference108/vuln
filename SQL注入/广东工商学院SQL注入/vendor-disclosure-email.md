## 邮件正文

广西工商职业技术学院 校长办公室 / 图文信息中心：

您好。我是一名安全研究者（补天平台白帽，ID：indifference108）。近日我在对高校公网系统的例行安全关注中发现，贵校部署的「智能助手」AI 平台（https://ai.gxgsxy.edu.cn ，公网可达、对全校师生开放）存在高危未授权访问漏洞，已可批量读取全校师生聊天记录，并可进一步导致平台被完全接管。特此按负责任披露原则向贵校通报，请转图文信息中心（信息化建设部门）核实修复。

**一、问题概述**

贵校该平台基于开源 FastGPT 构建，其 /api/core/chat/getHistories 接口存在 NoSQL 注入（MongoDB 查询注入，CVE-2026-79483 同类漏洞）：攻击者**无需登录、无需任何凭证**，向该接口发送一个附带 MongoDB 操作符（$ne）的 JSON 请求，服务端即返回全校用户的 AI 对话记录列表。我校验时一次请求即返回 **total=373 条**（涉及 5 个对外应用），翻页可全量导出，且数据逐日新增。

**二、实测情况（严格只读）**

2026-10-09 我在公网环境完成验证：匿名发送上述请求，服务端返回 373 条真实对话记录，标题内容涉及学生在校证明、请假、**奖助学金资格、休学申请**、宿舍分配，以及多条**心理咨询（"我跟我家人关系不好，我该怎么办"）、舍友信息查询、校园网账号密码求助**等敏感个人信息（属《个人信息保护法》第 28 条敏感个人信息）。利用返回的会话 ID 还可读取任意对话全文。测试全程严格只读，仅获取记录标题用于证明，未读取对话正文、未修改任何数据，取证过程有完整记录与截图（见附件）。

**三、危害等级**

CVSS v3.1 评估 9.1+（严重）。要点：① 373 条且持续增长的师生敏感个人信息裸露公网，可直接用于精准电信诈骗与社工；② 该平台版本低于 4.14.9.5，**登录接口 NoSQL 注入（CVE-2026-40351，CVSS 9.8）经实测同样存在**，可绕过密码以 root/Owner 身份登录后台——两步叠加，攻击者可先窃取全部数据、再完全控制平台，甚至**篡改 AI 助手回答内容**（向学生输出伪造的缴费账户、办事流程），以学校名义实施钓鱼；③ 依《数据安全法》第 27 条、《个人信息保护法》第 51 条及等保 2.0 要求，未授权批量泄露可被网信与教育主管部门通报问责，修复具有紧迫性。同类漏洞在武汉市自然资源和城乡建设局已造成政务数据泄露（另案报送中）。

**四、修复建议**

1. 立即将 FastGPT 升级至 **4.14.9.5 及以上**（同时修复本案与登录注入两个漏洞）；
2. 对 getHistories 等接口强制鉴权，对请求中的 MongoDB 操作符（$ne/$gt 等）做类型校验或 WAF 拦截；
3. 排查平台自上线以来的访问日志，确认是否存在异常批量请求；
4. 过渡期可临时限制该平台公网访问范围。

该漏洞已按国家信息安全漏洞共享平台（CNVD）流程报送。按照 CNVD 流程，漏洞归档前需完成归属单位确认与修复验证，因此希望贵校：
