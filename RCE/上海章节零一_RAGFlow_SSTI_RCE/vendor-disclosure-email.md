**一、问题概述**

贵司平台使用的 RAGFlow 版本为 v0.24.0，低于官方修复版本 v0.25.0。该版本 Agent 画布中的 Message 组件在渲染用户自定义消息内容时，使用未启用沙箱的 jinja2 模板引擎直接渲染（`agent/component/message.py`）。任何可登录系统的用户（贵平台开放自助注册，即任意互联网用户）在创建 Agent 时，可在消息内容中插入模板表达式，经由 Python 对象继承链获得操作系统接口，最终以容器内 root 身份执行任意命令。

官方已在 v0.25.0 修复此问题（改用 SandboxedEnvironment，commit 6fdca2d2），并公开了对应 CVE 编号。

**二、实测情况**

2026-10-06 我在公网环境对贵平台实例做了严格只读的验证：
